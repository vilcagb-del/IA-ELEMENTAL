# IA ELEMENTAL - Catálogo Interactivo de Plataformas de Inteligencia Artificial 🤖✨

Una aplicación web moderna, intuitiva e interactiva desarrollada con **React + Vite**, que ofrece información actualizada, comparativa de precios y funciones detalladas de las 5 grandes plataformas de IA:

- **Microsoft Copilot** (Windows 11, Office 365, Designer)
- **Canva Magic Studio** (Magic Media, Magic Write, Diseño IA)
- **Google Gemini** (Gemini 1.5 Pro, Multimodal, Workspace)
- **Dropbox Dash & AI** (Búsqueda Universal, Resumen de PDFs)
- **ChatGPT (OpenAI)** (GPT-4o, GPT-o1, Voice Mode, Canvas)

---

## 🚀 Cómo ejecutar localmente

1. Abre tu terminal en la carpeta del proyecto:
   ```bash
   cd "IA ELEMENTAL"
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre `http://localhost:3000` en tu navegador.

## 📦 Vinculación a GitHub y Despliegue en VERCEL

### Paso 1: Subir a GitHub
Abre la terminal en la raíz del proyecto y ejecuta:

```bash
git init
git add .
git commit -m "Initial commit - Catálogo de IA"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
git push -u origin main
```

*(Reemplaza `TU-USUARIO` y `TU-REPOSITORIO` con los datos de tu cuenta de GitHub).*

### Paso 2: Publicar en Vercel
1. Ve a [Vercel.com](https://vercel.com) e inicia sesión con tu cuenta de **GitHub**.
2. Haz clic en **"Add New..." → "Project"**.
3. Selecciona tu repositorio de GitHub `TU-REPOSITORIO`.
4. Vercel detectará la configuración automáticamente (`vercel.json` y `package.json` ya están incluidos).
5. Haz clic en **"Deploy"**. En menos de 1 minuto tendrás tu enlace HTTPS público listo para compartir.

## ✨ Características de la Aplicación

- 🎨 **Diseño Glassmorphic Premium**: Efectos de neón, tarjetas translúcidas y modo Oscuro/Claro interactivo.
- 🔍 **Búsqueda en Tiempo Real & Filtros**: Filtra por categoría (Productividad, Diseño, Conversacional, Archivos) o por palabras clave.
- 📊 **Tabla Comparativa de Precios**: Visualización interactiva de costos mensuales vs. anuales con descuento.
- 💡 **Recomendador Inteligente ("¿Qué IA necesitas?")**: Quiz rápido de 2 preguntas que te recomienda la IA idónea.
- 🔍 **Modales de Detalle Profundo**: Información de cada plataforma con pros, contras, funciones y enlaces directos.
