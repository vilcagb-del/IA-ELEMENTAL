🚀 Despliegue en GitHub & Vercel

Abre tu terminal en la carpeta del proyecto y ejecuta estos comandos para subirlo a tu GitHub:

git init
git add .
git commit -m "Initial commit - IA Elemental Web"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/ia-elemental.git
git push -u origin main

Luego ingresa a Vercel.com, inicia sesión con GitHub y haz clic en "Import Project". ¡Vercel lo publicará gratis en segundos con enlace HTTPS!
